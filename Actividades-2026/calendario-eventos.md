# 📅 Calendario de Eventos de la Comunidad

## Acerca de este calendario

Este calendario es un espacio centralizado para visibilizar y coordinar los eventos de la comunidad Python Colombia y otros eventos relevantes para el ecosistema Python en las diferentes comunidades del país.

**Nuestro objetivo:**
- 🗺️ Mapear y compartir eventos Python a nivel nacional e internacional
- 🤝 Fortalecer la conexión entre comunidades Python en Colombia
- 📢 Facilitar la participación y organización de encuentros
- 🌟 Impulsar la colaboración y el conocimiento compartido

Este calendario incluye:
- Reuniones y planificaciones de Python Colombia
- Eventos locales (PyDays, workshops, meetups)
- Eventos internacionales relevantes para nuestra comunidad (PyCon, conferencias)

---

## ¿Cómo agregar un nuevo evento?

Para agregar un nuevo evento al calendario, simplemente añade una nueva fila a la tabla con la siguiente información:

- **Fecha**: Escribe el mes (Enero, Febrero, etc.), seguido del día/rango de días. Para eventos de varios días, usa el formato "Mes Día-Día" (ej: Mayo 13-19)
- **Horario**: Escribe el horario del evento, o la hora de inicio (ej: De 9:00 a 11:00)
- **Nombre del Evento**: Título descriptivo del evento (Mantenlo corto)
- **Ciudad**: Ubicación del evento u "Online" si es virtual
- **Link**: Enlace al registro o página del evento

### Ejemplo:
```
| Marzo 15-16 | Todo el día | Workshop Python Avanzado | Bogotá | [Registro](https://ejemplo.com) |
```
